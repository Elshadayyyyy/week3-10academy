# End-to-End Insurance Risk Analytics & Predictive Modeling

## Project Overview
This project focuses on analyzing historical car insurance claim data to help AlphaCare Insurance Solutions (ACIS) optimize marketing strategies and identify low-risk clients for premium adjustments. By leveraging Exploratory Data Analysis (EDA), statistical testing, and predictive modeling, the project aims to provide actionable insights that improve business decision-making.
The originally mentioned dataset in the assignment was not available. An alternative dataset, which contains similar features and is suitable for analysis is used instead.

---

## Dataset
The dataset used contains information on 1,338 insurance policies with the following columns:

- **age**: Age of the policyholder  
- **sex**: Gender of the policyholder
- **bmi**: Body Mass Index of the policyholder  
- **children**: Number of children covered under the policy  
- **smoker**: Smoker status of the policyholder
- **region**: Region of the policyholder
- **charges**: Medical charges billed
